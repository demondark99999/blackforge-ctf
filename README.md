## 🏅 PARA QUIEN SE ATREVA A LEVANTAR EL TELÓN

Este no es un repositorio de código cualquiera.

Es el resultado de fases meticulosas de diseño, construcción y verificación — cada línea escrita con la intención de crear un laboratorio de entrenamiento que exija pensamiento crítico, metodología y resiliencia.

Dentro de estos directorios encontrarás:

* Dos entornos interconectados construidos con infraestructura como código
* Servicios y aplicaciones configurados para simular escenarios reales de defensa y ataque
* Documentación técnica que explica la intención detrás de cada componente
* Una estructura diseñada para probar, no para entregar respuestas fáciles

Esta plataforma no fue hecha para ser resuelta en horas.
Fue hecha para ser entendida, explorada y respetada.

Como tal:
